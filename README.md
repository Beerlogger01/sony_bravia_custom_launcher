# Sony Bravia Launcher

Нативный домашний экран Android TV 7 с четырьмя HDMI, избранными приложениями и событийной панелью Home Assistant. Версия 1.2.0-rc1 проходит испытания. В комплекте два APK и пользовательская интеграция Bravia Launcher. Интеграция привязывает каждый телевизор отдельным одноразовым кодом и передаёт только выбранные комнаты и сущности.
