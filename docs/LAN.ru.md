# Прямое подключение по домашней сети · 1.2.0-rc2

После появления RC2 в основной ветке или доступном теге откройте Bravia Launcher в Marketplace, обновите установленную интеграцию и перезапустите Core. При выборе версии включите предварительные выпуски, если RC доступен как prerelease. Открытый PR сам по себе не доставляет обновления. Существующая запись и выбор датчиков сохраняются.

1. В параметрах записи телевизора откройте «Локальная сеть (HTTP)», включите режим и укажите фактический частный IPv4 телевизора. В «Карточках» проверьте существующую выборку. Оставьте Allow control пустым для режима чтения.
2. Из распакованного ZIP запустите в папке windows диагностику и обновление. Скрипт использует установленный adb.exe, сохраняет исходный HOME и старые APK, устанавливает оба обновления с сохранением данных.
3. В интеграции выберите «Выдать код». На ТВ откройте панель HA → «Подключение», включите «Локальная сеть (HTTP)», введите адрес HA и восемь цифр, нажмите «Привязать телевизор». Эта сборка разрешает открытый транспорт только к одному IPv4 сервера на порту 8123, заданному при сборке через -PbraviaLanHost. Код действует три минуты. При следующем открытии Home или Panel сохранённый ключ используется автоматически.
4. Измените состояние выбранного датчика и проверьте показание. При обрыве связи отметка актуальности меняется. После восстановления приходит новый снимок. Для отзыва выберите «Отозвать доступ». Изменение режима или адреса ТВ требует нового кода.

HTTP передаёт код, ключ, действия и показания открытым текстом. Клиент в сети с возможностью перехватить или изменить трафик может прочитать данные или подменить сервер. Проверка адреса TCP и ограниченные права уменьшают последствия утечки. При подозрении на перехват отзовите ключ в HA. Для HTTPS действует обычная проверка TLS. Режим HTTP требует прямого маршрута и стабильных адресов.

В Windows PowerShell после извлечения ZIP:

```powershell
$env:BRAVIA_TV = Read-Host 'IPv4 телевизора с портом 5555'
.\diagnose.ps1
.\update.ps1
```

Штатный HOME сохранён. Команда аварийного возврата:

```powershell
& "$env:USERPROFILE\Desktop\platform-tools\adb.exe" -s $env:BRAVIA_TV shell am start -n com.google.android.leanbacklauncher/.MainActivity
```

При изменённом HOME используйте restore.ps1 -Backup с каталогом исходной копии. Скрипт восстанавливает HOME. Обратная установка старых APK с меньшим versionCode не выполняется.
