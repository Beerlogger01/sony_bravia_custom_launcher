# Bravia Launcher 1.2.0-rc1

Нативный домашний экран Sony Android TV 7 (API 24). Home запускает приложения и системные входы, Panel получает события Home Assistant. Для возврата на штатную оболочку доступна физическая Home. Открытие HA в браузере и экспериментальный kiosk зависят от версии WebView и совместимости дашборда.

## Установка интеграции

1. Скопируйте каталог `custom_components/bravia_launcher` в `/config/custom_components/bravia_launcher` вместе с переводами. Перезапустите Home Assistant.
2. Откройте **Настройки → Устройства и службы → Добавить интеграцию → Bravia Launcher**. Введите название телевизора. Для второго телевизора создайте ещё одну запись.
3. В параметрах записи откройте **Карточки**. Укажите области либо сущности. Пустой выбор показывает пустую панель. Избранное и разрешения управления действуют в пределах этого выбора. Датчики можно закрепить и на ТВ. Путь существующего дашборда скопируйте из адресной строки HA, начиная с косой черты.
4. Откройте **Выдать код**. На ТВ в нативной панели откройте **Подключение**, введите HTTPS origin HA и восьмизначный код, нажмите **Привязать телевизор**. Одноразовый код действует три минуты, лимит составляет восемь попыток на все экраны за три минуты. Повторная привязка меняет ключ. **Отозвать доступ** закрывает текущий поток. В статусе отображается время последнего контакта.
5. Для обновления через встроенный Marketplace в HA 2026.11 откройте его в настройках, добавьте URL репозитория как пользовательский репозиторий типа «Интеграция», когда интеграция окажется в его основной ветке или доступном теге. До слияния PR используйте ручную установку из этой ветки. Публикация в общем каталоге отдельная. [Документация Marketplace](https://www.home-assistant.io/blog/2026/11/04/release-202611/)

## HTTPS внутри домашней сети

Для интеграции нужен доступный с ТВ HTTPS origin. HA по обычному HTTP самостоятельно сертификат не получает. Один конкретный вариант — локальная DNS-запись для имени Pi, сертификат с этим DNS-именем в Subject Alternative Name и включение TLS у встроенного сервера HA. Установите сертификат и закрытый ключ сервера в каталог /ssl на HA OS. Для своего CA установите на ТВ только публичный корневой сертификат через системное хранилище, если прошивка поддерживает импорт. При отсутствии импорта используйте публично доверенный сертификат на собственный домен, локальную DNS-запись и подтверждение владения DNS-01. Перенаправление портов из интернета не нужно. Проверьте резервный локальный доступ к HA перед изменением транспорта. Пример индивидуальной настройки встроенного HTTP-сервера, если он должен перейти на TLS:

```yaml
http:
  ssl_certificate: /ssl/fullchain.pem
  ssl_key: /ssl/privkey.pem
```

Сохраните остальные параметры существующего раздела http. Переход на HTTPS затрагивает и другие клиенты HA. Прежний HTTPS bridge можно продолжать использовать по прежнему адресу. Интеграция работает внутри Core без supervisor-токена и контейнера. Она хранит хеш выделенного TV-ключа, Android хранит ключ за AES-GCM в Android Keystore. События реестров и состояний объединяются в короткие пакеты. При каждом подключении передаётся snapshot, далее изменения и удаления. История интеграции ограничена интервалами в пять минут и последними сутками наблюдений во время подключения, очищается после перезапуска. Светом и выключателями можно управлять только по разрешённому ключу сущности и только через два фиксированных действия. Каталог поддерживает датчики независимо от веб-браузера.

## Обновление существующих APK

Распакуйте комплект, откройте PowerShell в папке windows. Укажите адрес вашего телевизора. По умолчанию adb.exe ищется в platform-tools на рабочем столе. Путь можно переопределить переменной BRAVIA_ADB.

```powershell
$env:BRAVIA_TV = Read-Host 'Адрес телевизора с портом 5555'
.\diagnose.ps1
.\update.ps1
```

Вначале сохраняются resolver, настройки, пакеты и обе старые APK в %LOCALAPPDATA%\BraviaHome. Храните каталог только на своём компьютере. При ошибке прямого pull используется уникальная копия в Download. Сверяются размер и SHA-256. Если один из install -r прерван, повторите команду после восстановления соединения. Сообщение различает подтверждённые установки и неясный результат текущей команды. Удаление данных и downgrade в этот сценарий не входят.

**Аварийный возврат при сбое приложения** из уже авторизованного PowerShell:

```powershell
& "$env:USERPROFILE\Desktop\platform-tools\adb.exe" -s $env:BRAVIA_TV shell am start -n com.google.android.leanbacklauncher/.MainActivity
```

Если HOME меняли ранее через поддерживаемый сценарий, выполните `.\restore.ps1 -Backup <путь>` с исходной копией для этого ТВ. На API 24 штатный Leanback может иметь более высокий приоритет. Даже успешный set-home-activity в этом случае не меняет результат нажатия Home. Переместите ярлык Bravia в начало ряда приложений, если прошивка это позволяет. Для проверки физической кнопки используйте check-home.ps1 до и после обычной перезагрузки. Скрипт сам не перезагружает телевизор.

## Источники и измерения

Карта строится по активным inputId и совпадающим hardware ID из dumpsys tv_input. Неактивные дубликаты допускаются. Конфликт активных записей останавливает обновление до установки. Проверьте каждую из четырёх плиток по реальной картинке и звуку и повторите после обычной перезагрузки. При отсутствии подтверждённой карты используются однозначные системные метки или штатный селектор. Пользовательские названия и порядок хранятся отдельно. Управление питанием, громкостью, CEC и Cast остаётся в системных компонентах и существующей интеграции Sony.

Для сравнения версий снимите одни и те же показатели из adb shell при одинаковых разрешении, составе карточек, состоянии сети и активном экране:

```sh
dumpsys meminfo house.bravia.home
dumpsys meminfo house.bravia.panel
dumpsys cpuinfo
am start -W -n house.bravia.home/com.gathin.tvhome.BraviaHome
dumpsys package house.bravia.home
dumpsys package house.bravia.panel
```

Ожидаемые versionCode — 15 и 3. Для холодного замера сначала завершите только процессы двух пользовательских APK. Проверьте пульт, все HDMI, CEC, эфир, Cast, Screen Mirroring, управление Sony из HA и текущий дашборд на физическом устройстве. Для управления с телефона используйте существующую интеграцию Sony и дашборд HA.
